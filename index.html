GET ITThree ways in, none of them an installer

The whole game is one HTML file. There is nothing to build, nothing to sign up for, and no dependency tree to audit before you can read the code.

1 · Play it right now

The copy on this site is the current build. Open play.html and you are in. Saves live in your browser's localStorage — nothing is uploaded anywhere, and nothing phones home.

2 · Download the latest

Grab a snapshot of the repository — or just the one file, which is genuinely all you need:

# the whole project
curl -L https://github.com/vonglurt/codexofconquest/archive/refs/heads/main.zip -o codexofconquest.zip

# or only the game, ~5.5 MB, playable offline forever
curl -L -O https://raw.githubusercontent.com/vonglurt/codexofconquest/main/play.html
open play.html

Releases, when they are cut, are on the releases page. There is no build artefact to choose between — the tag is the file.

3 · Clone it and run the tools

git clone https://github.com/vonglurt/codexofconquest.git
cd codexofconquest
make install        # restores src/node_modules
make                # lists every target
make play           # API + monitor, opens the game
make edit           # the world editor
make check          # the full gate chain
make test           # 960 Playwright tests

The node project lives in src/, not the repo root — see src/NODE.md for why, and for how to run npm directly.

THE SHORT VERSIONWhat the README says, in a paragraph

Codex of Conquest is a single-file adventure RPG. The combat engine, world map, NPC dialogue, quest system, save system, hundreds of monsters and eight acts of story all live inside one HTML file. No server, no build step, no install, no account. You can email it to someone.

It is a quest-driven, MUD-style game built on D&D 5e mechanics that stay visible: the advantaged d20, the stat modifier, the DC and the result are all shown rather than hidden behind an animation. You play one Human Fighter Champion from level 1 to 20, crossing 416 nodes across four towns against a 49-day clock.

The authoring tool ships with it. edit.html is a visual editor for nodes, terrains, monsters, quests, NPCs and mission bits — the flags the world reads to know what you have already done. A set of CI gates checks the world for dead links, unreachable nodes, duplicate keys and quests that can never complete.

Everything is MIT licensed. Not source-available — actually MIT. Read the full README.

THE PREMISEA dying courier, and a map you did not ask for

You are in the streets of Birka when a young man in a brown courier's satchel rounds a corner too fast and collapses at your feet. His coat is dark with blood. He presses a folded, stained map into your hand and says one word before his eyes close: "Sweelinck."

The Codex of Seven Seals binds the Void. Seven scholar-kings each carried one Shard into hiding before they died, and the seals are weakening now — monsters walk where they never walked, and the sky over Birka flickers. The courier found six of the seven. The seventh would have meant walking back through Birka, and the Void's outriders were already following him. He ran anyway, because the map had to reach someone.

That someone is you. The Void is not a fog of consuming darkness. It is a conqueror — it advances where the defenders are thin and retreats where they are strong. You have until Day 49.

WHO IT IS FORIf you miss text that respected you

This is built for people who played MUDs at 2am and still think about them. For people who like D&D 5e mechanics visible on screen — the advantaged d20, the stat modifier, the DC, the result — instead of hidden behind an animation. For roguelike and interactive-fiction readers who want prose that carries weight, and for tinkerers who want to open the file and change the world themselves.

It is a quest-driven, MUD-style RPG: you read, you choose a verb, you walk somewhere, something happens, and the world remembers. There is no twitch input and nothing to install. If you have ever wanted a game you could email to a friend as a single attachment, this is that.

The architecture is its own argument: the thing you make should be giveable.

THE CLASSYou are a Fighter, and everything follows from that

You play a single Human Fighter Champion from level 1 to 20. Not a party — one person, crossing a continent. Every system below is built around what a fighter can actually do: walk, look, fight, carry, ask, endure. You are frequently the hired help in someone else's story, and the game is honest about that. You witness more than you command.

🚶Walking

Movement is a real system, not a menu. A cell grid with roads, junctions and sea lanes; terrain decides your encounter rate; distance costs you days against a 49-day clock.

🗺️World map

416 nodes across four towns and eight acts — Birka, Tilbury, Visby, Weimar — with a live minimap, a region view and auto-travel along the road network.

⚔️D&D 5e combat

Initiative, AC, advantage, criticals, damage dice. 398 monsters across tiers, with the whole roll shown to you: d20, modifier, target, outcome.

◆Quest system

2,853 quests. Escort vignettes, waypoint deliveries, arcs that span acts. Arrival can complete a quest — walking to the right place is the verb.

🎣Fishing games

Not one minigame but several: bait selection, cast timing against a pool table, day and night species, rod and tackle upgrades, and a readable in-game Fishing Guide. Catches feed the economy, quests and the inn ledger.

🎲Skill checks

STR, DEX, CON, INT, WIS, CHA — and Luck as a seventh stat. Named DCs, visible rolls, and failure that costs you time rather than ending the run.

💬NPCs & favour

204 NPC profiles and 213 dialogue sets. Favourability rises when you choose people over efficiency, and the ending names the friends you kept.

🔖Mission bits

The world's memory. Every witnessed event sets a bit, and gates, quests and dialogue read them — so the world knows what you have already done.

🌑Void pressure

The real loss condition. Pressure builds where defenders are thin; the Epic Battlegrounds are twenty specific failures waiting for someone with your capability.

💀Death & loot

Death leaves a corpse and a grave marker you can walk back to. Loot tables, weapon economy, and an honest message about what you lost.

🖋️Tattoos & progression

A progression track carried in ink. Perks, badges and marks that survive into New Game+ along with the journal you filled.

🌐Multiplayer mesh

Optional. Run the local server and your world joins a peer mesh — presence, chat, consensual duels, shared maps, hash-chained ledgers.

THE DICEAn advantaged d20, and every modifier shown

Every outcome in the game resolves on a d20, and the game shows you the whole sum. Not a result — the arithmetic.

Roll with advantage and two dice appear side by side; the higher is taken and the discarded die stays on screen so you can see what you were spared. Roll with disadvantage and the lower one wins instead. Terrain, injury, gear, a friend standing next to you, a tattoo you earned nine hours ago — any of them can grant it.

On top of the die sits your custom stat modifier. Six abilities — STR, DEX, CON, INT, WIS, CHA — plus Luck as a seventh stat that behaves like none of the others. Point-buy at character creation, then proficiency, class bonuses and situational modifiers stack on top. A skill check names its DC before you commit, so a hard roll is a decision rather than a surprise.

d20 + STR 3 + prof 2 + advantage = 22 vs DC 14 → PASS
The story does not resolve the battle. The dice do.

Combat runs the same way: initiative, armour class, attack rolls, criticals on a natural 20, damage dice by weapon, and 398 monsters tiered so that walking somewhere you are not ready for is legible before it is fatal. Failure usually costs you days against the 49-day clock rather than ending the run — the Void advances while you recover.

THE STORY LAYERA journal that stops mid-page

The courier's name was Froberger. His journal is found early and read in fragments — seventeen entries, five of which are read aloud at specific places in the world. Entry 41 is the last one. He stopped writing in the middle of the page, and the blank line below it is not an accident.

The game's theme is the curse of knowledge: once you understand something, you can no longer remember what it was like not to. Froberger saw the Void clearly and tried telling people. They could not hear it. So he stopped telling and started fixing, and became the only one who could do what needed doing — and that, not anything with teeth, is what destroyed him. In New Game+, you write Entry 42.

There are four endings. One of them names every person you helped, by name. One of them does not.

BUILD THE WORLDedit.html — the authoring tool

The game ships with its own editor. edit.html is a visual world builder where nodes, terrains, monsters, quests, NPCs and mission bits are set, configured and edited — the same bits the game reads at runtime to decide what has happened and what is now possible.

Point it at the local API server and you can add a town, wire a road, write a quest chain and watch it appear in the running game. The whole authoring pipeline emits a documented quest format, and a set of CI gates check the world for dead links, unreachable nodes, duplicate keys and quests that can never complete.

Run it locally

git clone https://github.com/vonglurt/codexofconquest.git
cd codexofconquest
make run          # monitor + API server + opens the game
make worldbuilder # the authoring tool, API and monitor

Or skip all of it and just open play.html in a browser. The game needs nothing else.

OPEN SOURCEDownload it, fork it, take it apart

Codex of Conquest is MIT licensed. Not source-available, not a demo — actually MIT. Copy it, modify it, sell it, ship your own world built on it. The one file is the whole product: no build step, no bundler, no dependency tree to audit before you can read the code.

Good first contributions

  • Write a quest arc. The quest format is documented and the editor is visual — you do not need to touch the engine.
  • Add a region. Nodes, terrains and roads are data; the map solver lays them out.
  • Balance something. Monster tiers, drop rates and the XP curve are all tables.
  • Take a backlog row. Open work is tracked in six phase backlogs under docs/backlog/, each row written with its evidence and its grep-to-disprove.
  • Fix a lab report. Over a hundred engineering write-ups live in docs/lab-reports/, each verified against the live file.

Read CONTRIBUTING.md before starting — it carries the working rules, including the existing-work-first policy that has saved several rewrites of work that was already shipped.
