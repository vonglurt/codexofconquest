# docs/ — Reference & design documentation

Secondary documentation. The **core sync docs** stay at the repo root
(`index.md`, `world.md`, `story.md`, `mechanics.md`, `monsters.md`, `maps.md`,
`quest.md`) because they are kept in two-way sync with `play.html` and are
referenced constantly. Everything here is reference/history that changes less often.

| Folder | Contents |
|--------|----------|
| `spec/` | JavaScript architecture specs — `spec-engine`, `spec-world`, `spec-combat`, `spec-migration`, `spec-corridors` (archived), plus `combat.md`. |
| `story/` | Narrative arc write-ups — coastal, epic-battlegrounds, investigation, ng-plus, npc-dialogues, and `story-flowchart.md`. |
| `api/` | WBAPI docs — `API-README`, `wbapi-help`, `api-user-guide`, `api-faq`, `api-data-audit`. |
| `mechanics/` | Mechanics deep-dives — `mechanics-combat`, `mechanics-economy` (companions to `design/mechanics.md`). |
| `design/` | The design docs of record — `story`, `quest`, `world`, `mechanics`, `monsters`, `maps`, `potential`, `prompt`, `index`. |
| `backlog/` | `BACKLOG.md` + the six phase backlogs + `plan-archive.md`. |
| `lab-reports/` | 114 engineering write-ups, each verified against the live game file. |
| `archive/` | Superseded records. Annotated, never rewritten. |
| `maps/` | Generated `node-index.md` and map lab reports. |
| `notes/` | Dev/design notes — dev-environment, node-network, cell-resume-prompts, brainstorm-one-liners, IEEE cell-grid paper, data-code-migration, restart-prompt, say, ux-first-battles, IntegrationPlan, Year1367AD. |

Start at **`design/index.md`** for the master cross-reference table.
